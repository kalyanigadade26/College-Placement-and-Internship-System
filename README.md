# College Placement and Internship System

## Project Description
The College Placement and Internship System is a web-based application developed to automate and simplify placement and internship activities within a college.

This system provides an online platform for students, administrators, and companies to manage recruitment processes efficiently and effectively.

---

## Features

### Student Module
- Student Registration and Login
- Apply for Jobs and Internships
- View Placement Opportunities
- Upload Resume
- Track Application Status

### Admin Module
- Manage Students
- Manage Companies
- Post Placement Drives
- View Applications
- Manage Internship Opportunities

### Company Module
- Company Registration and Login
- Post Jobs and Internships
- View Student Applications
- Select Eligible Candidates

## How to Run the Project

1. Install XAMPP
2. Copy the project folder into:
```text
htdocs
```

3. Start Apache and MySQL using XAMPP Control Panel

4. Open phpMyAdmin

5. Create a new database

6. Import the:
```text
database.sql
```

7. Open browser and run:
```text
http://localhost/College-Placement-and-Internship-System
```
